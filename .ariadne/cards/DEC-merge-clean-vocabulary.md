# DEC-merge-clean-vocabulary: Use honest three-way merge outcome vocabulary

- Status: DECIDED
- Provenance: DECIDED
- Type: DEC
- Revised: 2026-08-30

## Statement

Use CLEAN, DIVERGED, and FAILED outcomes; CLEAN means only that no deterministic conflict was detected under explicit identity and topology rules, not that arbitrary semantic convergence was proven.
