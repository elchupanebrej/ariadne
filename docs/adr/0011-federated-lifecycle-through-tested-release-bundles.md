# Federated lifecycle through tested release bundles

The Method Contract, Teaching Skills, adapters, kernel, examples, and receipts keep owner-controlled versions and lifecycle authority; a non-normative Tested Release Bundle pins one exact evidence-backed combination. This rejects a lockstep release train so direct owner use and independent change remain possible, while owner-issued impact receipts, pin-preserving migration, and executable retirement checks prevent silent incompatibility and permanent compatibility debt.
