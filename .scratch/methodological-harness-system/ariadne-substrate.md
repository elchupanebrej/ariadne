# Ariadne substrate: methodological harness system

## Observed facts

- [`OBS-methodological-guide-self-application`](../../.ariadne/GRAPH.jsonl) — `docs/designing_methodological_guides.md` already requires a meaningful task, a complete worked example, practical verification, lifecycle governance, and self-application through A0 and A1–A7.
- [`FRAME-methodology-skill-harness-system`](../../.ariadne/GRAPH.jsonl) — a fresh agent session must be able to learn Ariadne, apply it, emit the required artifacts, and verify the result without hidden oral context.
- [`ASM-fresh-session-reteaching`](../../.ariadne/GRAPH.jsonl) — until falsified, every invocation is treated as having only the instructions and artifacts explicitly loaded for it.

## Resolved decisions

- [`DEC-wayfinder-destination-specification`](../../.ariadne/GRAPH.jsonl) — the map stops at a decision-complete specification and dependency-wired implementation map.
- [`DEC-orchestration-runtime-in-scope`](../../.ariadne/GRAPH.jsonl) — the target candidate is a new runtime that complements Matt Pocock Skills and Ariadne; research may still falsify its necessity.
- [`DEC-staged-self-application`](../../.ariadne/GRAPH.jsonl) — authoring is recursively bootstrapped in stages; runtime dependencies remain acyclic.
- [`DEC-neutral-orchestration-subsystem`](../../.ariadne/GRAPH.jsonl) — the runtime is a neutral third subsystem, pending the explicit Ariadne validation request.
- [`DEC-compact-method-contract`](../../.ariadne/GRAPH.jsonl) — one compact versioned Method Contract owns executable normative truth.
- [`DEC-minimum-orchestration-contract`](../../.ariadne/GRAPH.jsonl) — the Orchestration Harness owns only host-neutral, repository-visible attempt continuity and fail-closed advancement; no standalone service is approved.
- [`DEC-method-contract-shape`](../../.ariadne/GRAPH.jsonl) — one typed JSON manifest owns the method's compact executable truth; standard schema predicates and closed effect records prevent prose parsing or host-language callbacks.
- [`DEC-staged-fixed-point-contract`](../../.ariadne/GRAPH.jsonl) — immutable owner-gated rounds separate the build provenance DAG from the smaller runtime DAG; structural v1 requires two independent complete no-delta `P/A/R/L` assessments and never consumes empirical receipts.
- [`DEC-ariadne-teaching-skill-contract`](../../.ariadne/GRAPH.jsonl) — a thin task-first lesson routes one complete parser decision progressively, then checks explanation, fading, and changed-case transfer without copying Ariadne rules or the Method Contract.
- [`DEC-matt-ariadne-adapter-contract`](../../.ariadne/GRAPH.jsonl) — one pointer-only five-operation lifecycle surface coordinates owner-specific Matt and Ariadne envelopes while direct use and semantic ownership remain intact; real boundary conformance remains a Rung 6 obligation.
- [`DEC-runtime-safety-recovery-contract`](../../.ariadne/GRAPH.jsonl) — trusted-host, owner-gated runtime semantics default replay to zero, serialize dispatch intent, preserve pointer-only recovery and observability, and stop every unauthorized, conflicting, expired, canceled, or ambiguous path without inferred compensation.
- [`DEC-methodological-harness-lifecycle`](../../.ariadne/GRAPH.jsonl) — component owners retain version and lifecycle authority while immutable Tested Release Bundles pin exact evidence-backed combinations and preserve attempt pins through migration and retirement.
- [`DEC-kernel-packaging-substrate`](../../.ariadne/GRAPH.jsonl) — if a kernel survives the thin-baseline evaluation, it is one deletable owner-neutral TypeScript module with a separate per-attempt JSONL ledger and local atomic file transactions, not an Ariadne extension or standalone service.

## Frontier

- [`ASM-dedicated-runtime-necessity`](../../.ariadne/GRAPH.jsonl) — the neutral boundary is coherent, but a clean-session baseline must still show that a separate runtime owns at least one necessary behavior unavailable from thinner candidates.
- [`EVDREQ-clean-session-runtime-necessity`](../../.ariadne/GRAPH.jsonl) — a Rung 6 comparison must delete or inline the kernel if a thinner eligible implementation satisfies the same contract.
- [`EVDREQ-runtime-safety-recovery-r8`](../../.ariadne/GRAPH.jsonl) — Rung 8 fault injection must exercise crashes, concurrent resumers, replay budgets, cursor conflicts, cancellation races, expiry, ambiguity, recovery, and secret-free observability across real owner boundaries.

## Candidate set

- [`CAN-dedicated-orchestration-runtime`](../../.ariadne/GRAPH.jsonl) — selected conditionally: a minimal library, CLI, or in-process kernel owns attempts and pointers without taking over owner semantics or state.
- [`CAN-layered-method-skill-harness`](../../.ariadne/GRAPH.jsonl) — falsification fallback: keep the harness inside the existing loader and Ariadne CLI if research finds no missing runtime behavior.
- [`VAL-SELECT-methodological-harness-defaults`](../../.ariadne/GRAPH.jsonl) — selection remains open until research and a clean-session pilot test the runtime-necessity assumption.
- [`VAL-SELECT-minimum-orchestration-contract`](../../.ariadne/GRAPH.jsonl) — rejects prose-only enforcement and standalone-runtime expansion while retaining the thin baseline as the selected kernel's deletion test.
- [`VAL-SELECT-method-contract-shape`](../../.ariadne/GRAPH.jsonl) — selects the single embedded-schema manifest after rejecting a custom-keyword schema document and a premature multi-file bundle.
- [`CAN-staged-snapshot-fixed-point`](../../.ariadne/GRAPH.jsonl) — selected fixed-point mechanism: pinned build stages, two isolated self-applications, conservative core normalization, and fail-closed owner handoff on every delta.
- [`CAN-live-recursive-self-hosting`](../../.ariadne/GRAPH.jsonl) — rejected because active mutual invocation violates runtime acyclicity and immutable provenance.
- [`CAN-detached-fixed-point-audit`](../../.ariadne/GRAPH.jsonl) — rejected because snapshot comparison alone does not execute `Apply(M,M)` and permits duplicated authoring semantics.
- [`VAL-SELECT-staged-fixed-point-contract`](../../.ariadne/GRAPH.jsonl) — rejects live recursion and audit-only comparison before preferences; staged snapshots are the only candidate to pass every hard invariant.
- [`CAN-task-first-progressive-teaching`](../../.ariadne/GRAPH.jsonl) — selected teaching mechanism: a meaningful task, triggered rule loading, complete artifacts, self-explanation, fading, transfer, and one executable check.
- [`CAN-reference-manual-teaching`](../../.ariadne/GRAPH.jsonl) — rejected because bulk rule loading violates progressive disclosure and duplicates Ariadne summaries.
- [`CAN-method-contract-wrapper-teaching`](../../.ariadne/GRAPH.jsonl) — rejected because copied normative content violates source ownership and change locality.
- [`VAL-SELECT-ariadne-teaching-skill`](../../.ariadne/GRAPH.jsonl) — selects the task-first lesson after the reference manual and wrapper fail hard requirements.
- [`CAN-owner-gated-runtime-safety`](../../.ariadne/GRAPH.jsonl) — selected semantics: one pointer-only attempt boundary validates authority and owner receipts while physical enforcement and semantic effects stay with their owners.
- [`VAL-SELECT-runtime-safety-recovery`](../../.ariadne/GRAPH.jsonl) — rejects ungated host delegation and a central control plane before preferences; the selected boundary remains provisional until real-boundary and fault-injection evidence exists.
- [`CAN-colocated-neutral-file-kernel`](../../.ariadne/GRAPH.jsonl) — selected conditionally: one internal module supplies atomic attempt continuity without taking over owner state or adding a deployment lifecycle.
- [`CAN-thin-owner-artifact-baseline`](../../.ariadne/GRAPH.jsonl) — retained as the mandatory deletion baseline; it replaces the kernel if matched Rung 6 evidence satisfies every hard invariant.
- [`CAN-ariadne-controller-kernel`](../../.ariadne/GRAPH.jsonl) — rejected because it would merge orchestration attempts into Ariadne's epistemic ownership.
- [`CAN-standalone-sqlite-kernel`](../../.ariadne/GRAPH.jsonl) — rejected because no current requirement pays for a package, service, database, or migration lifecycle.

## Evidence

- [`EVD-modern-agent-harness-practices`](../../.ariadne/GRAPH.jsonl) — primary sources conditionally support a minimal neutral kernel for cross-session cursor, artifact gates, recovery, approvals, replay safety, version pins, and trace correlation.
- [`EVD-neutral-orchestration-boundary-r1`](../../.ariadne/GRAPH.jsonl) — Ariadne Rung 1 supports the neutral ownership boundary; implemented adapters still require Rung 6.
- [`VAL-neutral-orchestration-boundary-r1`](../../.ariadne/GRAPH.jsonl) — every hard ownership requirement passes statically, while runtime necessity remains inconclusive.
- [`EVD-method-contract-shape-prototype`](../../.ariadne/GRAPH.jsonl) — seven deterministic scenarios support the selected Method Contract representation at Rung 3; adapter compatibility and fresh-session effectiveness remain downstream evidence.
- [`EVD-staged-fixed-point-prototype`](../../.ariadne/GRAPH.jsonl) — deterministic Rung 3 scenarios release only stable and presentation-only cases and stop normative deltas, missing independence, runtime cycles, and empirical-substitution attempts.
- [`EVD-ariadne-teaching-flow-prototype-r3`](../../.ariadne/GRAPH.jsonl) — deterministic Rung 3 scenarios complete the approved progressive lesson and reject bulk-rule and copied-contract paths; clean-session effectiveness remains open.
- [`EVD-matt-ariadne-adapter-prototype-r3`](../../.ariadne/GRAPH.jsonl) — nine deterministic Rung 3 paths support coordinated use, HITL resumption, direct-use import, cancellation acknowledgment, effect inspection, and fail-closed invalid paths.
- [`OBS-runtime-safety-post-decision-gate`](../../.ariadne/GRAPH.jsonl) — structural and semantic gates pass for the accepted safety contract; strict verification leaves its intentional Rung 8 request and the pre-existing clean-session request unsatisfied.
- [`EVD-kernel-packaging-prototype-r3`](../../.ariadne/GRAPH.jsonl) — ten deterministic paths and four candidate filters support the co-located neutral module at Rung 3 while leaving clean-session necessity and real filesystem safety open.
