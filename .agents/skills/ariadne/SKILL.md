# Ariadne

Load only the rule named by the active branch:

- Frame requirements apart from mechanisms: `rules/10-frame.md`.
- Diagnose symptoms with falsifiable causal hypotheses: `rules/20-diagnose.md`.
- Transform or trim a mechanism: `rules/30-transform.md`.
- Explore structurally distinct candidates: `rules/40-explore.md`.
- Resolve decision-significant unknowns: `rules/50-knowledge.md`.
- Analyze change coupling: `rules/60-dependencies.md`.
- Model queues, retries, and failure dynamics: `rules/70-dynamics.md`.
- Select candidates against hard requirements: `rules/80-value.md`.
- Validate claims or transitions: `rules/90-validate.md`.

For graph/provenance, evidence, invalidation, host roles, depth, or agent invariants, also load only the matching file: `rules/00-core.md`, `rules/evidence.md`, `rules/invalidation.md`, `rules/roles.md`, `rules/depth-modes.md`, or `rules/agent-rules.md`.
